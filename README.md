# Fútbol Promiedos

Este proyecto está inspirado en el sitio como Promiedos pero con un toque personal.

## Instrucciones para desplegar

- El formulario de contacto está configurado para enviar los datos a Formspree. Debes reemplazar el valor `yourformid` en el atributo `action` del formulario con tu ID real de Formspree.
- Para publicar el sitio, se puede usar GitHub Pages siguiendo estos pasos:
  1. Crear un repositorio en GitHub y subir los archivos.
  2. En la configuración del repositorio activar GitHub Pages en la rama `main` o `master`.
  3. Acceder a la URL pública que GitHub genere.
  
## Estructura del proyecto

- index.html: página principal con estructura semántica.
- styles.css: archivo con los estilos externos.
- imagenes/: carpeta con las imágenes usadas (debes agregar las tuyas).
