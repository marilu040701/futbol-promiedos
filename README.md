# Futbol Promiedos

Este proyecto está inspirado en el sitio como Promiedos pero con un toque personal (se agregó una sección de compra y reseñas de productos de futbol cosa que en la pagina original no lo tiene).

La preentrega contiene estructura semantica en HTML, estilos aplicados con CSS externo, diseño responsivo implementado con flexbox y grid, a su vez, tiene le formulario de contacto funcional mediante Formspree.

Tiene la navegacion interna entre secciones mediante anclas, multimedia intefrada, google fonts y fondos personalizados aplicados.

Pagina publicada en GitHun pages. 

URL https://marilu040701.github.io/futbol-promiedos
