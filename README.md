# Futbol Promiedos

Este proyecto está inspirado en el sitio como Promiedos pero con un toque personal (se agregó una sección de compra y reseñas de productos de futbol cosa que en la pagina original no lo tiene).

La preentrega contiene estructura semantica en HTML, estilos aplicados con CSS externo, diseño responsivo implementado con flexbox y grid, a su vez, tiene le formulario de contacto funcional mediante Formspree.

Con la entrega final se le agregó:la carga dinámica de productos utilizando una API REST pública, y se incorporó un carrito de compras totalmente funcional desarrollado con JavaScript, incluyendo agregado, eliminación, contador de productos y cálculo automático del total, todo persistido mediante localStorage. También se validó el formulario con JavaScript para mejorar la experiencia del usuario. Se implementó Bootstrap para mejorar el diseño responsivo y la presentación general del sitio, además de aplicar buenas prácticas de accesibilidad y metaetiquetas para optimización SEO.

Tiene la navegacion interna entre secciones mediante anclas, multimedia intefrada, google fonts y fondos personalizados aplicados.
